## What 3.6.22 changed (context for the pending nuances)

1. **Runner hint row is configurable.** `showRunnerKeyHints` (default true) under
   Settings → RadiProtocol seeds new sessions through `RunnerSessionHost` option
   `keyHintsVisibleByDefault`. `H` still toggles the current session. A collapsible
   `<details>` shortcut table sits directly under the toggle in the same settings section.
2. **Phrases moved to a nested settings page.** Main page → Insertion phrases → button opens
   `displayPhrasesPage()` in the same `PluginSettingTab` (not a second top-level Settings tab).
   Each row: trigger input on the left, insertion input on the right, icon button for
   auto/hotkey mode (updated in place, no re-render), delete button; Add phrase button at the
   bottom; per-row invalid-trigger highlight and a count at the top.
3. **Per-phrase modes replaced the global mode.** `auto` replaces while typing; `hotkey` waits for
   the command **`Insert phrase from trigger`** (`id: insert-phrase`). The command has no default
   hotkey; users assign one in Settings → Hotkeys. It replaces the whole word before the caret,
   only in RadiProtocol textareas tracked by `attachTextExpansion()` and in the note editor
   (respecting the **Expand in the note editor** toggle), never in search boxes/foreign inputs or
   runner chrome.
4. **Old Space-delimiter mode removed.** 3.6.21 `trigger => replacement` data migrates: `auto`
   lines → auto phrases, `delimiter` lines → hotkey phrases. Fresh installs get the symbol defaults.
5. **3.6.22 kept 3.6.21 fixes intact:** Ctrl+Space in runner free-text fields, digit badges on
   snippet choice pills, Tab/Shift+Tab in the snippet picker.

## Likely places the reported nuances may concern (ask, do not assume)

- Hint row: setting affects only **new** sessions; an already open runner keeps its current state.
  The cheat sheet is a collapsed `<details>` inside settings, not a modal or a separate page.
- Phrase page: it is a nested page of the RadiProtocol settings tab with a Back button, not a
  separate top-level settings tab. Add/delete re-renders the page, so scroll position may reset and
  a newly added blank row is not auto-focused. Insertions are single-line inputs (`$nl$` / `\n`
  for breaks). No per-row enable, reorder, swap, or regex.
- Hotkey mode: one shared command/chord for all hotkey phrases; no per-phrase commands. Needs a
  manual assignment in Settings → Hotkeys. If the user expected Space to keep working, that is
  the deliberate removal in item 4 above.
- Command target policy: focus must be in a RadiProtocol textarea or the note editor. The command
  shows a Notice when nothing matches, when expansion is disabled, or when editor expansion is off.
- Migration: old delimiter rules now need the chord; old auto rules behave as before.
- The 3.6.21 handoff's known limits still apply: no `$tb$` tabstops, no regex, no import from
  Substitutions/Text-Snippets, textarea replacement bypasses native undo.
